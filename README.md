## What we do

We're a two-person team building SaaS products on top of LLM agents — practical tools that automate real workflows for small and mid-size businesses.

No demos. No research. Shipped software.

## Focus areas

- **Agent orchestration** — designing and running multi-step LLM workflows that actually work in production
- **SaaS automation** — turning repetitive business processes into agents that handle them end-to-end
- **Open-source tooling** — sharing what we build along the way

## Open source

We publish tools, experiments, and utilities from our stack as we build. If it solved a problem for us, it might solve one for you.
